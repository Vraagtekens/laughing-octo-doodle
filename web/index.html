bevy sketches

Static WebAssembly exports from a Bevy sketchbook. Each folder opens as its own canvas route for embedding, testing, or drifting through.

sketches
default_template A tiny Bevy shader square used as the baseline WebAssembly sketch. mouse_trail A cursor-following square that stamps a fading trail through the scene. render_texture_template A layered render-texture sketch with shader-driven post processing. sprite_grid_trail A drifting image grid rendered into a feedback surface. feedback_sprite_grid A controllable feedback loop made from small moving sprite objects. slime_mold_loop A GPU-generated slime mold colony with a deterministic seamless loop.
